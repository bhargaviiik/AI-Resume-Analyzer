# AI Resume Analyzer

An LLM-powered resume analysis tool that extracts PDF content, evaluates 
resume structure, and identifies skill gaps against a target job description.

## Features
- PDF resume upload and text extraction
- AI-driven feedback via the Gemini API — structure evaluation and 
  actionable improvement suggestions
- Job description matching — keyword-overlap similarity scoring and 
  gap identification

## Tech Stack
- **Frontend:** React
- **Backend:** Node.js, Express
- **Database:** MongoDB
- **AI:** Gemini API
- **PDF Parsing:** pdf-parse
